*  PyPCNs

This repo implements a predictive coding network that can be trained in a supervised or unsupervised way with the MNIST dataset.

To run a supervised experiment with the MNIST dataset:

#+begin_src bash
python -m scripts.tsk_sup.main -dsn mnist -bs 60 60 -nbs 1000 150 -dimp 784 -dimt 0 -nitr 1 -ly 784 300 100 10 -af tanh -ic 50 50 -lr 0.001 -dt 0.01 -md supervised -lbp top
#+end_src

To visualise results:

#+begin_src bash
python -m scripts.tsk_sup.visualize -eid learning_rate
#+end_src

*Note*: this is work that was carried out during my PhD to understand how predictive coding networks work in practice; the code would benefit from some kind of refactoring and a detailed documentation.
